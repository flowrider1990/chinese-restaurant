# Gift vouchers with Stripe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Guests buy a gift voucher (25/50/100 € or 10–300 €) via Stripe Checkout (test mode), receive code + PDF by e-mail, and staff redeem it in the Payload admin with an append-only history.

**Architecture:** Everything inside the existing Next.js 16 + Payload 3.90 app, mirroring the reservation feature: pure rules in `src/lib`, a `vouchers` collection with admin-only access, a Server Action that creates a pending voucher and a Stripe Checkout Session, and a signed webhook (Payload collection endpoint) that marks it paid, generates the code, renders a PDF with `pdf-lib` and mails it through Payload's `sendEmail` (Resend adapter, attachments supported).

**Tech Stack:** Next.js 16.3.8 App Router, Payload 3.90.2 (SQLite/libSQL, migrations only), `stripe` 23.x (Node SDK), `pdf-lib` 1.17.1 (MIT), Vitest (unit + int projects), pnpm.

**Spec:** `docs/superpowers/specs/2026-10-14-vouchers-design.md`

## Global Constraints

- Amounts: quick picks 25, 50, 100 €; free amount 10–300 €, whole euros only.
- Money is stored as integer cents (project convention, `src/lib/price.ts`, `src/fields/price.ts`).
- Only Stripe test keys: a key not starting with `sk_test_` is refused.
- Secrets only in `.env` (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`); never `NEXT_PUBLIC_`; never print their values.
- Recipient name max. 80 characters, message max. 200, buyer name max. 100, e-mail max. 200.
- Valid until 31 December of the third year after purchase (Europe/Berlin calendar year).
- Code format `XC-XXXX-XXXX`, alphabet without 0/O/1/I/L.
- Copy in German uses the formal "Sie"; every UI string exists in DE and EN (`src/i18n/dictionary.ts`, `en` is typed as `typeof de`).
- Schema changes only through migrations (`push: false`). Generated `ALTER TABLE … ADD … REFERENCES` lacks `ON DELETE`; add it by hand (see `docs/architecture.md` → Known issues).
- Integration tests run against `data/test.db` with `RESEND_API_KEY: ''` (already set in `vitest.config.mts`); they never call the real Stripe API.
- Never stop or restart the user's running dev server. Commit only on this branch (`feature/vouchers`); do not push unless asked.
- Before writing Next.js code, consult `node_modules/next/dist/docs/` (AGENTS.md); before Stripe code, check the installed SDK's types.

## Review Focus

1. **Recipient name or message with characters Helvetica cannot encode** (Chinese characters — this is a Chinese restaurant — or emoji) → the PDF must still be generated, unsupported characters replaced, mail still sent. Test: Task 4.
2. **Webhook delivered twice, or `expired` arriving after `completed`** → exactly one code and one mail; a paid voucher never becomes expired. Test: Task 6.
3. **Buyer lands on the thank-you URL before the webhook arrived** → "Zahlung wird bestätigt …", not an error or "unknown". Test: Task 6 (`voucherStatusForSession`).
4. **Free amount typed as "25,50", "1e2", " 30 " or a tampered hidden value** → rejected with a clear message (or trimmed for spaces), never silently rounded or charged. Test: Task 2.
5. **Stripe unreachable or key missing when the form is submitted** → form shows "Bezahlung gerade nicht möglich …", the pending voucher becomes `expired`, nothing crashes. Test: Task 7.

```ts
import Stripe from 'stripe'

/** This is a demo: only Stripe test-mode keys are accepted, so no real money can ever be charged. */
export function assertTestKey(key: string | undefined): string {
  if (!key) throw new Error('STRIPE_SECRET_KEY is not set.')
  if (!key.startsWith('sk_test_'))
    throw new Error('Only Stripe test keys (sk_test_…) are allowed in this demo.')
  return key
}

let client: Stripe | null = null

/** Server-side Stripe client. Uses the API version pinned by the installed SDK. */
export function getStripe(): Stripe {
  return (client ??= new Stripe(assertTestKey(process.env.STRIPE_SECRET_KEY)))
}
```

```ts
import { randomInt } from 'crypto'

/** No 0/O, 1/I/L: codes are read aloud and typed from paper. 31 characters. */
export const CODE_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789'
export const CODE_PATTERN = /^XC-[A-HJKMNP-Z2-9]{4}-[A-HJKMNP-Z2-9]{4}$/

const block = () =>
  Array.from({ length: 4 }, () => CODE_ALPHABET[randomInt(CODE_ALPHABET.length)]).join('')

/** e.g. "XC-7K4M-9QPA". 31^8 ≈ 8.5 · 10^11 combinations; uniqueness is checked before saving. */
export function generateCode(): string {
  return `XC-${block()}-${block()}`
}
```

`src/lib/voucher-rules.ts`

```ts
export const VOUCHER_LIMITS = {
  min: 10,
  max: 300,
  presets: [25, 50, 100],
  buyerName: 100,
  email: 200,
  recipientName: 80,
  message: 200,
} as const

export type VoucherProblem = 'required' | 'invalid' | 'tooLong' | 'tooLow' | 'tooHigh'

export type VoucherInput = {
  /** Whole euros as typed or chosen, e.g. "50". */
  amount: string
  buyerName: string
  buyerEmail: string
  recipientName?: string
  message?: string
  privacy: boolean
}

const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/

/** "50" → 50. Anything but plain digits (decimals, exponents, signs) → null; never rounds. */
export function parseWholeEuros(raw: string): number | null {
  const value = raw.trim()
  return /^\d{1,4}$/.test(value) ? Number(value) : null
}

export function checkVoucherRequest(
  input: VoucherInput,
): Partial<Record<keyof VoucherInput, VoucherProblem>> {
  const problems: Partial<Record<keyof VoucherInput, VoucherProblem>> = {}
  const L = VOUCHER_LIMITS

  if (!input.amount.trim()) problems.amount = 'required'
  else {
    const euros = parseWholeEuros(input.amount)
    if (euros === null) problems.amount = 'invalid'
    else if (euros < L.min) problems.amount = 'tooLow'
    else if (euros > L.max) problems.amount = 'tooHigh'
  }

  const name = input.buyerName.trim()
  if (!name) problems.buyerName = 'required'
  else if (name.length > L.buyerName) problems.buyerName = 'tooLong'

  const email = input.buyerEmail.trim().toLowerCase()
  if (!email) problems.buyerEmail = 'required'
  else if (!EMAIL.test(email) || email.length > L.email) problems.buyerEmail = 'invalid'

  if ((input.recipientName ?? '').trim().length > L.recipientName) problems.recipientName = 'tooLong'
  if ((input.message ?? '').trim().length > L.message) problems.message = 'tooLong'
  if (!input.privacy) problems.privacy = 'required'
  return problems
}

/** 31 December of the third year after the purchase year (Berlin), 23:59:59 Berlin (UTC+1 in winter). */
export function validUntil(paidAt: Date): string {
  const year = Number(
    new Intl.DateTimeFormat('en', { timeZone: 'Europe/Berlin', year: 'numeric' }).format(paidAt),
  )
  return `${year + 3}-12-31T22:59:59.000Z`
}

export type RedemptionRow = {
  id?: string | null
  /** Cents. */
  amount: number
  note?: string | null
  redeemedAt?: string | null
  by?: unknown
}

export function balanceCents(amountCents: number, rows: { amount: number }[]): number {
  return amountCents - rows.reduce((sum, r) => sum + r.amount, 0)
}

const sameRow = (a: RedemptionRow, b: RedemptionRow) =>
  a.id === b.id &&
  a.amount === b.amount &&
  (a.note ?? '') === (b.note ?? '') &&
  (a.redeemedAt ?? null) === (b.redeemedAt ?? null)

/** Redemptions are append-only and never exceed the voucher amount. Returns an admin error or null. */
export function checkRedemptions({
  previous,
  next,
  amountCents,
  status,
  validUntil: until,
  now,
}: {
  previous: RedemptionRow[]
  next: RedemptionRow[]
  amountCents: number
  status: string
  validUntil?: string | null
  now: Date
}): string | null {
  if (next.length < previous.length || previous.some((row, i) => !sameRow(row, next[i])))
    return 'Frühere Einlösungen können nicht geändert oder gelöscht werden.'
  const added = next.slice(previous.length)
  if (added.length === 0) return null
  if (status !== 'paid') return 'Dieser Gutschein ist nicht einlösbar (nicht bezahlt oder storniert).'
  if (until && now.getTime() > new Date(until).getTime()) return 'Dieser Gutschein ist abgelaufen.'
  if (added.some((r) => !Number.isInteger(r.amount) || r.amount <= 0))
    return 'Der eingelöste Betrag muss größer als 0 sein.'
  if (balanceCents(amountCents, next) < 0) return 'Der Betrag ist höher als der Restbetrag.'
  return null
}
```

```ts
import { PDFDocument, StandardFonts, rgb, type PDFFont } from 'pdf-lib'
import { formatPrice } from './price'

export type PdfVoucher = {
  code: string
  /** Cents. */
  amount: number
  recipientName?: string | null
  message?: string | null
  validUntil: string
  locale: 'de' | 'en'
}
export type PdfRestaurant = { name: string; street: string; postalCode: string; city: string; phone: string }

const INK = rgb(0.118, 0.153, 0.251) // #1e2740
const COBALT = rgb(0.169, 0.341, 0.627) // #2b57a0
const SOFT = rgb(0.4, 0.43, 0.5)

/** The built-in Helvetica only covers WinAnsi (Latin, €, umlauts); other characters become "?". */
export function pdfSafe(text: string, supported: Set<number>): string {
  return [...text].map((c) => (c === '\n' || supported.has(c.codePointAt(0)!) ? c : '?')).join('')
}

/** Splits text into lines that fit `maxWidth` at `size`. */
function wrap(text: string, font: PDFFont, size: number, maxWidth: number): string[] {
  const lines: string[] = []
  for (const paragraph of text.split('\n')) {
    let line = ''
    for (const word of paragraph.split(/\s+/).filter(Boolean)) {
      const next = line ? `${line} ${word}` : word
      if (font.widthOfTextAtSize(next, size) <= maxWidth) line = next
      else {
        if (line) lines.push(line)
        line = word
      }
    }
    lines.push(line)
  }
  return lines
}

/** A5 landscape gift voucher (595 × 420 pt). */
export async function voucherPdf(v: PdfVoucher, r: PdfRestaurant): Promise<Uint8Array> {
  const doc = await PDFDocument.create()
  const en = v.locale === 'en'
  doc.setTitle(`${en ? 'Gift voucher' : 'Gutschein'} ${r.name} ${v.code}`)
  const page = doc.addPage([595, 420])
  const regular = await doc.embedFont(StandardFonts.Helvetica)
  const bold = await doc.embedFont(StandardFonts.HelveticaBold)
  const supported = new Set(regular.getCharacterSet())
  const safe = (s: string) => pdfSafe(s, supported)
  const margin = 40
  const width = 595 - margin * 2

  page.drawRectangle({ x: 16, y: 16, width: 563, height: 388, borderColor: COBALT, borderWidth: 2 })
  page.drawText(safe(r.name), { x: margin, y: 360, size: 22, font: bold, color: COBALT })
  page.drawText(en ? 'Gift voucher' : 'Gutschein', { x: margin, y: 320, size: 30, font: bold, color: INK })
  page.drawText(formatPrice(v.amount, en ? 'en-GB' : 'de-DE'), { x: margin, y: 270, size: 40, font: bold, color: INK })

  let y = 236
  if (v.recipientName?.trim()) {
    page.drawText(safe(`${en ? 'For' : 'Für'} ${v.recipientName.trim()}`), { x: margin, y, size: 14, font: regular, color: INK })
    y -= 22
  }
  if (v.message?.trim()) {
    for (const line of wrap(safe(v.message.trim()), regular, 11, width).slice(0, 4)) {
      page.drawText(line, { x: margin, y, size: 11, font: regular, color: SOFT })
      y -= 15
    }
  }

  page.drawText(en ? 'Code' : 'Code', { x: margin, y: 104, size: 10, font: regular, color: SOFT })
  page.drawText(v.code, { x: margin, y: 80, size: 24, font: bold, color: COBALT })
  const until = new Intl.DateTimeFormat(en ? 'en-GB' : 'de-DE', { day: 'numeric', month: 'long', year: 'numeric', timeZone: 'Europe/Berlin' }).format(new Date(v.validUntil))
  page.drawText(safe(`${en ? 'Valid until' : 'Gültig bis'} ${until}`), { x: margin, y: 60, size: 10, font: regular, color: SOFT })
  page.drawText(safe(`${r.street}, ${r.postalCode} ${r.city} · ${r.phone}`), { x: margin, y: 36, size: 9, font: regular, color: SOFT })
  page.drawText(en ? 'DEMO – not a real voucher' : 'DEMO – kein echter Gutschein', { x: 400, y: 36, size: 9, font: bold, color: SOFT })

  return doc.save()
}
```

```ts
import type { Payload } from 'payload'
import type { Voucher } from '@/payload-types'
import { sendVoucherMails } from './voucher-mails'
import { generateCode } from './voucher-code'
import { validUntil } from './voucher-rules'

export type SessionLike = {
  id: string
  payment_status?: string | null
  payment_intent?: string | { id: string } | null
  amount_total?: number | null
}

async function bySession(payload: Payload, sessionId: string): Promise<Voucher | null> {
  const res = await payload.find({
    collection: 'vouchers',
    where: { stripeSessionId: { equals: sessionId } },
    limit: 1,
    depth: 0,
  })
  return res.docs[0] ?? null
}

async function unusedCode(payload: Payload): Promise<string> {
  for (let attempt = 0; attempt < 5; attempt++) {
    const code = generateCode()
    const taken = await payload.count({ collection: 'vouchers', where: { code: { equals: code } } })
    if (taken.totalDocs === 0) return code
  }
  throw new Error('Could not find an unused voucher code')
}

/**
 * pending → paid exactly once: the update only matches a still-pending voucher, so a repeated
 * webhook event changes nothing and sends no second mail.
 */
export async function markPaid(payload: Payload, session: SessionLike, now = new Date()) {
  const voucher = await bySession(payload, session.id)
  if (!voucher) {
    payload.logger.error(`Stripe session ${session.id}: no voucher found`)
    return 'unknown' as const
  }
  if (voucher.status !== 'pending') return 'already' as const
  if (typeof session.amount_total === 'number' && session.amount_total !== voucher.amount)
    payload.logger.error(`Voucher ${voucher.id}: paid ${session.amount_total} cents, expected ${voucher.amount}`)

  const intent = typeof session.payment_intent === 'string' ? session.payment_intent : session.payment_intent?.id
  const result = await payload.update({
    collection: 'vouchers',
    where: { and: [{ id: { equals: voucher.id } }, { status: { equals: 'pending' } }] },
    data: {
      status: 'paid',
      code: await unusedCode(payload),
      paidAt: now.toISOString(),
      validUntil: validUntil(now),
      stripePaymentIntent: intent ?? null,
    },
  })
  if (result.errors.length > 0) throw new Error(`Voucher ${voucher.id}: ${result.errors[0].message}`)
  const updated = result.docs[0]
  if (!updated) return 'already' as const
  await sendVoucherMails(payload, updated as Voucher)
  return 'paid' as const
}

/** Checkout session timed out or the checkout could not start: a pending voucher becomes expired. */
export async function expireSession(payload: Payload, sessionId: string) {
  await payload.update({
    collection: 'vouchers',
    where: { and: [{ stripeSessionId: { equals: sessionId } }, { status: { equals: 'pending' } }] },
    data: { status: 'expired' },
  })
}

/** For the thank-you page. Reads our DB only; never exposes the code or personal data. */
export async function voucherStatusForSession(payload: Payload, sessionId: string) {
  if (!/^cs_[A-Za-z0-9_]+$/.test(sessionId)) return 'unknown' as const
  const v = await bySession(payload, sessionId)
  if (!v) return 'unknown' as const
  return v.status === 'paid' ? ('paid' as const) : v.status === 'pending' ? ('pending' as const) : ('unknown' as const)
}
```

```ts
import type { Payload } from 'payload'
import type Stripe from 'stripe'
import { expireSession, markPaid, type SessionLike } from './voucher-fulfilment'

/**
 * Verifies a Stripe webhook and applies it. 400 for a bad signature (nothing changed), 500 when
 * our side failed (Stripe retries), 200 otherwise, including events we do not handle.
 */
export async function handleStripeEvent({
  payload,
  stripe,
  rawBody,
  signature,
  secret,
}: {
  payload: Payload
  stripe: Stripe
  rawBody: string
  signature: string | null
  secret: string | undefined
}): Promise<{ status: number; body: Record<string, unknown> }> {
  if (!secret) {
    payload.logger.error('STRIPE_WEBHOOK_SECRET is not set; Stripe webhooks are rejected.')
    return { status: 500, body: { error: 'Webhook not configured' } }
  }
  let event: Stripe.Event
  try {
    event = stripe.webhooks.constructEvent(rawBody, signature ?? '', secret)
  } catch {
    return { status: 400, body: { error: 'Invalid signature' } }
  }

  try {
    const session = event.data.object as SessionLike
    switch (event.type) {
      case 'checkout.session.completed':
      case 'checkout.session.async_payment_succeeded':
        if (session.payment_status === 'paid') await markPaid(payload, session)
        break
      case 'checkout.session.expired':
        await expireSession(payload, session.id)
        break
    }
    return { status: 200, body: { received: true } }
  } catch (error) {
    payload.logger.error(`Stripe event ${event.id}: ${error instanceof Error ? error.message : String(error)}`)
    return { status: 500, body: { error: 'Processing failed' } }
  }
}
```

```ts
import type { Payload } from 'payload'
import type Stripe from 'stripe'
import { href } from '@/i18n/routes'
import { absolute } from './seo'
import { checkVoucherRequest, parseWholeEuros, type VoucherInput, type VoucherProblem } from './voucher-rules'

export type CheckoutResult =
  | { ok: true; url: string }
  | { ok: false; problems: Partial<Record<keyof VoucherInput, VoucherProblem>>; unavailable?: true }

const SESSION_MINUTES = 30
const unavailable = { ok: false, problems: {}, unavailable: true } as const

/**
 * Checks the request again on the server, stores a pending voucher and opens a Stripe Checkout
 * Session for it. Kept outside the Server Action so it can be tested without Next.js.
 */
export async function startVoucherCheckout({
  payload,
  stripe,
  input,
  locale,
  now = new Date(),
}: {
  payload: Payload
  stripe: () => Pick<Stripe, 'checkout'>
  input: VoucherInput & { website?: string }
  locale: 'de' | 'en'
  now?: Date
}): Promise<CheckoutResult> {
  // Honeypot: humans never see the field.
  if (input.website) return { ok: false, problems: {} }
  const problems = checkVoucherRequest(input)
  if (Object.keys(problems).length > 0) return { ok: false, problems }

  let client: Pick<Stripe, 'checkout'>
  try {
    client = stripe()
  } catch (error) {
    payload.logger.error(`Voucher checkout: ${error instanceof Error ? error.message : String(error)}`)
    return unavailable
  }

  const cents = parseWholeEuros(input.amount)! * 100
  const email = input.buyerEmail.trim().toLowerCase()
  const voucher = await payload.create({
    collection: 'vouchers',
    data: {
      status: 'pending',
      amount: cents,
      buyerName: input.buyerName.trim(),
      buyerEmail: email,
      recipientName: input.recipientName?.trim() || undefined,
      message: input.message?.trim() || undefined,
      locale,
      privacyAcceptedAt: now.toISOString(),
    },
  })

  const page = absolute(href('vouchers', locale))
  try {
    const session = await client.checkout.sessions.create({
      mode: 'payment',
      line_items: [
        {
          quantity: 1,
          price_data: {
            currency: 'eur',
            unit_amount: cents,
            product_data: { name: locale === 'en' ? 'Gift voucher Xiao Chu' : 'Gutschein Xiao Chu' },
          },
        },
      ],
      customer_email: email,
      locale,
      client_reference_id: String(voucher.id),
      metadata: { voucherId: String(voucher.id) },
      expires_at: Math.floor(now.getTime() / 1000) + SESSION_MINUTES * 60,
      // Stripe replaces {CHECKOUT_SESSION_ID}; it must not be URL-encoded.
      success_url: `${page}?session_id={CHECKOUT_SESSION_ID}`,
      cancel_url: page,
    })
    if (!session.url) throw new Error(`Session ${session.id} has no URL`)
    await payload.update({ collection: 'vouchers', id: voucher.id, data: { stripeSessionId: session.id } })
    return { ok: true, url: session.url }
  } catch (error) {
    payload.logger.error(`Voucher ${voucher.id}: checkout failed: ${error instanceof Error ? error.message : String(error)}`)
    await payload.update({ collection: 'vouchers', id: voucher.id, data: { status: 'expired' } })
    return unavailable
  }
}
```

- [ ] **Step 3: Server Action** — `src/app/(frontend)/[locale]/gutscheine/actions.ts`

```ts
'use server'

import { redirect } from 'next/navigation'
import { payloadClient } from '@/lib/queries'
import { getStripe } from '@/lib/stripe'
import { startVoucherCheckout, type CheckoutResult } from '@/lib/voucher-checkout'

/** Form submit. Every rule is checked again on the server inside startVoucherCheckout. */
export async function buyVoucherAction(_prev: CheckoutResult | null, form: FormData): Promise<CheckoutResult> {
  const str = (key: string) => {
    const v = form.get(key)
    return typeof v === 'string' ? v : ''
  }
  const choice = str('amount')
  const result = await startVoucherCheckout({
    payload: await payloadClient(),
    stripe: getStripe,
    locale: str('locale') === 'en' ? 'en' : 'de',
    input: {
      amount: choice === 'other' ? str('customAmount') : choice,
      buyerName: str('buyerName'),
      buyerEmail: str('buyerEmail'),
      recipientName: str('recipientName') || undefined,
      message: str('message') || undefined,
      privacy: form.get('privacy') === 'on',
      website: str('website') || undefined,
    },
  })
  // redirect() throws; it must stay outside any try/catch (Next.js docs: functions/redirect.md).
  if (result.ok) redirect(result.url)
  return result
}
```

```tsx
'use client'

import Link from 'next/link'
import { useActionState, useState } from 'react'
import { dictionaries } from '@/i18n/dictionary'
import type { Locale } from '@/i18n/locales'
import type { CheckoutResult } from '@/lib/voucher-checkout'
import { VOUCHER_LIMITS } from '@/lib/voucher-rules'
import { buyVoucherAction } from './actions'

export function VoucherForm({ locale, privacyHref }: { locale: Locale; privacyHref: string }) {
  const t = dictionaries[locale].vouchers
  const [state, action, pending] = useActionState<CheckoutResult | null, FormData>(buyVoucherAction, null)
  const [values, setValues] = useState({
    amount: '50',
    customAmount: '',
    buyerName: '',
    buyerEmail: '',
    recipientName: '',
    message: '',
  })
  const [privacy, setPrivacy] = useState(false)
  const bind = (field: keyof typeof values) => ({
    value: values[field],
    onChange: (e: { target: { value: string } }) => setValues((v) => ({ ...v, [field]: e.target.value })),
  })
  const problems = state && !state.ok ? state.problems : {}
  const err = (field: keyof typeof problems) =>
    problems[field] ? (
      <p className="field__error" id={`${field}-error`}>
        {t.problems[problems[field]!]}
      </p>
    ) : null
  const described = (...ids: (string | false | undefined)[]) => ids.filter(Boolean).join(' ') || undefined
  const euro = new Intl.NumberFormat(locale === 'de' ? 'de-DE' : 'en-GB', { style: 'currency', currency: 'EUR', maximumFractionDigits: 0 })

  return (
    <form action={action} className="reserve-form voucher-form" noValidate>
      {state && !state.ok && (state.unavailable || Object.keys(state.problems).length > 0) && (
        <p className="reserve-form__summary" role="alert">
          {state.unavailable ? t.unavailable : t.errorSummary}
        </p>
      )}
      <input type="hidden" name="locale" value={locale} />
      <div className="reserve-form__hp" aria-hidden="true">
        <label>
          Website <input type="text" name="website" tabIndex={-1} autoComplete="off" />
        </label>
      </div>

      <fieldset className="field amount-picks" aria-describedby={described(problems.amount && 'amount-error')}>
        <legend>{t.amount}</legend>
        <div className="amount-picks__options">
          {[...VOUCHER_LIMITS.presets.map(String), 'other'].map((value) => (
            <label key={value} className="amount-pick">
              <input type="radio" name="amount" value={value} checked={values.amount === value} onChange={bind('amount').onChange} />
              <span>{value === 'other' ? t.other : euro.format(Number(value))}</span>
            </label>
          ))}
        </div>
        {values.amount === 'other' && (
          <div className="amount-picks__custom">
            <label htmlFor="customAmount">{t.otherLabel}</label>
            <input
              id="customAmount"
              name="customAmount"
              inputMode="numeric"
              pattern="[0-9]*"
              autoComplete="off"
              {...bind('customAmount')}
              aria-invalid={Boolean(problems.amount)}
              aria-describedby={described('custom-hint', problems.amount && 'amount-error')}
            />
            <p className="field__hint" id="custom-hint">
              {t.otherHint(VOUCHER_LIMITS.min, VOUCHER_LIMITS.max)}
            </p>
          </div>
        )}
        {err('amount')}
      </fieldset>

      <div className="field field--half">
        <label htmlFor="buyerName">{t.buyerName}</label>
        <input id="buyerName" name="buyerName" type="text" required maxLength={VOUCHER_LIMITS.buyerName} autoComplete="name" {...bind('buyerName')} aria-invalid={Boolean(problems.buyerName)} aria-describedby={described(problems.buyerName && 'buyerName-error')} />
        {err('buyerName')}
      </div>
      <div className="field field--half">
        <label htmlFor="buyerEmail">{t.buyerEmail}</label>
        <input id="buyerEmail" name="buyerEmail" type="email" required maxLength={VOUCHER_LIMITS.email} autoComplete="email" {...bind('buyerEmail')} aria-invalid={Boolean(problems.buyerEmail)} aria-describedby={described('email-hint', problems.buyerEmail && 'buyerEmail-error')} />
        <p className="field__hint" id="email-hint">{t.emailHint}</p>
        {err('buyerEmail')}
      </div>
      <div className="field field--half">
        <label htmlFor="recipientName">{t.recipientName}</label>
        <input id="recipientName" name="recipientName" type="text" maxLength={VOUCHER_LIMITS.recipientName} {...bind('recipientName')} aria-invalid={Boolean(problems.recipientName)} aria-describedby={described('recipient-hint', problems.recipientName && 'recipientName-error')} />
        <p className="field__hint" id="recipient-hint">{t.recipientHint}</p>
        {err('recipientName')}
      </div>
      <div className="field">
        <label htmlFor="message">{t.message}</label>
        <textarea id="message" name="message" rows={3} maxLength={VOUCHER_LIMITS.message} {...bind('message')} aria-invalid={Boolean(problems.message)} aria-describedby={described('message-hint', problems.message && 'message-error')} />
        <p className="field__hint" id="message-hint">{t.messageHint(VOUCHER_LIMITS.message)}</p>
        {err('message')}
      </div>

      <div className="field field--check">
        <input id="privacy" name="privacy" type="checkbox" checked={privacy} onChange={(e) => setPrivacy(e.target.checked)} required aria-invalid={Boolean(problems.privacy)} aria-describedby={described(problems.privacy && 'privacy-error')} />
        <label htmlFor="privacy">
          {t.privacy}{' '}
          <Link href={privacyHref} target="_blank">{t.privacyLink}</Link>
        </label>
        {err('privacy')}
      </div>

      <p className="voucher-form__demo">{t.demo}</p>
      <button type="submit" className="btn btn--primary" disabled={pending}>
        {pending ? t.sending : t.submit}
      </button>
    </form>
  )
```

- [ ] **Step 5: Page** — `src/app/(frontend)/[locale]/gutscheine/page.tsx`

```tsx
import type { Metadata } from 'next'
import Link from 'next/link'
import { dictionaries } from '@/i18n/dictionary'
import { href } from '@/i18n/routes'
import { getLocale, isLocale } from '@/i18n/server'
import { payloadClient } from '@/lib/queries'
import { pageMetadata } from '@/lib/seo'
import { voucherStatusForSession } from '@/lib/voucher-fulfilment'
import { VoucherForm } from './VoucherForm'

export async function generateMetadata({ params, searchParams }: PageProps<'/[locale]/gutscheine'>): Promise<Metadata> {
  const { locale } = await params
  if (!isLocale(locale)) return {}
  const meta = await pageMetadata({ key: 'vouchers', locale, title: dictionaries[locale].vouchers.title })
  // The thank-you state is per order and must not be indexed.
  return (await searchParams).session_id ? { ...meta, robots: { index: false, follow: false } } : meta
}

export default async function VouchersPage({ searchParams }: PageProps<'/[locale]/gutscheine'>) {
  const { locale, t } = await getLocale()
  const sessionId = (await searchParams).session_id
  const v = t.vouchers

  if (typeof sessionId === 'string') {
    const status = await voucherStatusForSession(await payloadClient(), sessionId)
    const [title, text] =
      status === 'paid' ? [v.paidTitle, v.paid] : status === 'pending' ? [v.pendingTitle, v.pending] : [v.unknownTitle, v.unknown]
    return (
      <div className="reserve-page">
        <section className="reserve-success" role="status">
          <h1>{title}</h1>
          <p>{text}</p>
          <p>
            {status === 'pending' ? (
              <a href={`${href('vouchers', locale)}?session_id=${encodeURIComponent(sessionId)}`}>{v.reload}</a>
            ) : (
              <Link href={href('vouchers', locale)}>{v.back}</Link>
            )}
          </p>
        </section>
      </div>
    )
  }

  return (
    <div className="reserve-page">
      <header className="page-head">
        <h1>{v.title}</h1>
        <p>{v.intro}</p>
      </header>
      <VoucherForm locale={locale} privacyHref={href('privacy', locale)} />
    </div>
  )
}
```
